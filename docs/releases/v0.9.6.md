# AROMOTION Portable v0.9.6

This beta fixes the camera-follow problem reported during real Windows testing.

## Camera changes

- Replaced the old scale+crop camera with a center-based FFmpeg `zoompan` model.
- The focus target is treated as the viewport center and clamped against all four frame edges.
- Correctly supports top-left, top-right, bottom-left, bottom-right, center, and intermediate positions.
- Added a safe-zone camera follower instead of raw mouse chasing.
- Added low-pass damping, speed limiting, and smoothstep interpolation to reduce shake.
- Zoom-in now glides from neutral frame center toward the interaction target.
- Follow flexibility now changes both dead-zone size and response speed.

## Cursor changes

- Reconstructed cursor now uses continuous ASS `\move()` paths rather than static cursor snapshots.
- Added adaptive smoothing: small hand jitter is damped more aggressively while larger intentional movement gets faster response.

## Quality

- MP4 High motion render now uses H.264 CRF 8 with `yuv444p` 4:4:4 to preserve screen text and UI edges better.
- Lossless MKV remains FFV1 for mathematically lossless output.

## Recommended test

Enable auto zoom and mouse follow, set Follow Flexibility around 60-70%, then click in this order: center → top-right → bottom-right → bottom-left → top-left. The camera should travel to each quadrant instead of remaining anchored toward the top-left.
